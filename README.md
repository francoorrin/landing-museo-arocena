# Restaurante Temático Museo Arocena - Landing Page

Landing page promocional y sistema de reservas para la propuesta del Restaurante Temático dentro del Museo Arocena en Torreón, Coahuila.

## 🚀 Características
- **Identidad visual:** Alto impacto estético inspirado en diseño minimalista contemporáneo y contexto cultural.
- **Menús dinámicos:** Inspirados en las exposiciones temporales vigentes (Ciclo actual: París en la Belle Époque - Siglo XIX).
- **Base de datos en la nube:** Integración directa con **Supabase PostgreSQL** para recepción de reservas en tiempo real.
- **Despliegue:** Optimizado para hosting estático de alta velocidad en **Vercel**.

## 🛠️ Tecnologías
- HTML5, Tailwind CSS, JavaScript ES6
- Supabase Database (PostgreSQL + RLS)
- Vercel Edge Hosting
